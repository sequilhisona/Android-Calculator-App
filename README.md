# Android Calculator App

A simple, clean Android Calculator application built using Java and XML layouts.

## Features
- Addition (`+`), Subtraction (`−`), Multiplication (`×`), and Division (`÷`)
- Input validation for empty fields and division-by-zero protection
- Clean Material-inspired layout (`activity_main.xml`)
- One-tap **CLEAR ALL** reset functionality

## Project Structure
- `app/src/main/res/layout/activity_main.xml` — User interface layout
- `app/src/main/java/com/example/calculator/MainActivity.java` — Application logic and event listeners
- `app/src/main/AndroidManifest.xml` — App configuration and launcher activity declaration
